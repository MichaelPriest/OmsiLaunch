# Documentation OmsiLaunch

Il s'agit de la documentation canonique en anglais pour OmsiLaunch `0.1.0-beta1`.
OmsiLaunch fournit un lancement, une gestion de session et un temps d'exécution programmables
contrôle de la version exacte d'OMSI 2 documentée dans la référence de compatibilité.

Commencez par [installation](getting-started/installation.md) et
[votre première session](getting-started/installation.md). Le
[référence de contrôle local](getting-started/installation.md) documente la CLI et les
surface de contrôle d’exécution. Voir [limitations connues](getting-started/installation.md)
avant de s’appuyer sur des capacités expérimentales.

Des copies localisées sont disponibles sous `docs/localized/`. L'anglais est normatif
lorsque la formulation technique diffère.

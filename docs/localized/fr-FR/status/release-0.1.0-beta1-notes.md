# OmsiLaunch 0.1.0-bêta1

**Bag préparé :** `v0.1.0-beta1`  
**Titre de la version :** `OmsiLaunch 0.1.0-beta1`  
**Pré-version :** oui

## Faits saillants

- `LaunchSpec`, `PlanSession`, cycle de vie de session et référence programmables
  Des CLI sont disponibles pour le profil de build OMSI pris en charge.
- Les fichiers de plugins de produits permanents sont installés sous `plugins\OmsiLaunch.*`.
- La configuration temporaire et les modifications de démarrage gérées sont journalisées et restaurées
  octet pour octet.
- Les ressources splash gérées par PTB, ENG, DEU et FRA sont incluses.
- Le package Release comprend un exemple de session Grundorf portable et un petit
  guide de l'utilisateur hors ligne.

## Compatibilité

Cette version bêta prend uniquement en charge « Omsi23004_692EBFBF ». OMSI inconnu ou non profilé
les exécutables sont rejetés. Consulter le catalogue de capacités et les limitations connues
avant de dépendre des contrôles d'exécution expérimentaux.

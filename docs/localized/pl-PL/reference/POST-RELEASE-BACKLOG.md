# Zaległości po wydaniu

Status: NORMATYWNY

Pierwsza bieżąca wersja nie może ujawniać niebezpiecznych mutacji ogólnego wskaźnika/listy.
Poniższe prace celowo powstały po wydaniu, chyba że są ściśle powiązane z profilem
operacja semantyczna zamyka się przed bramką zwalniającą:

- Bezpieczne wprowadzenie czasu działania i weryfikacja cykli utraty/resetowania urządzenia D3D9 oraz a
  poproś o zresetowanie wyścigów. Stan urządzenia i tworzenie tekstur/aktualizacja/zapytanie/wydanie
  są już sprawdzone w działaniu dzięki nieprzezroczystym uchwytom OmsiLaunch.
- Ponowne łączenie pojazdów między płytkami/przestrzennymi/ODE. Transformacje lokalne nie są poprawne
  teleport lub prymityw replikacji autorytetu.
- Autorytatywna kontrola pojazdów marionetkowych o wysokiej częstotliwości.
- Ogólne zapisy wskaźników/list i niskopoziomowe interfejsy API ODE.
- Tryb zgodności OmsiHook RPC.
- Starsze porty NT6 i XP, po zamrożeniu `legacy-port-base`.

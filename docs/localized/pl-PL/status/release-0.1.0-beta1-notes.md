# OmsiLaunch 0.1.0-beta1

**Tag przygotowany:** `v0.1.0-beta1`  
**Tytuł wydania:** `OmsiLaunch 0.1.0-beta1`  
**Wstępne wydanie:** tak

## Najważniejsze informacje

- Programowalne `LaunchSpec`, `PlanSession`, cykl życia sesji i odniesienie
  Interfejs CLI jest dostępny dla obsługiwanego profilu kompilacji OMSI.
- Stałe pliki wtyczek produktów są instalowane w katalogu `plugins\OmsiLaunch.*`.
— Tymczasowa konfiguracja i zarządzane zmiany powitalne są rejestrowane i przywracane
  bajt po bajcie.
- Uwzględniono zasoby powitalne zarządzane przez PTB, ENG, DEU i FRA.
- Pakiet Release zawiera przenośny przykład sesji Grundorf i mały plik
  podręcznik użytkownika offline.

## Zgodność

Ta wersja beta obsługuje tylko `Omsi23004_692EBFBF`. Nieznany lub nieprofilowany OMSI
pliki wykonywalne są odrzucane. Zapoznaj się z katalogiem możliwości i znanymi ograniczeniami
wcześniej, w zależności od eksperymentalnych kontroli czasu wykonania.

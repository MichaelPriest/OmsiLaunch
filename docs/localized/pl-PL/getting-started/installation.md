# Instalacja

Rozpakuj `OmsiLaunch-0.1.0-beta1.zip` bezpośrednio do katalogu głównego
obsługiwanej instalacji OMSI. Pakiet umieszcza `OmsiLaunch.exe` i zależności
kontrolera w katalogu głównym oraz stałe pliki produktu w `plugins\`.

`.omsilaunch\` to prywatny katalog OmsiLaunch dla zasobów, diagnostyki i
tymczasowego dziennika. Nie przenoś tam binariów pluginu. Pluginy innych firm
nie są własnością transakcji OmsiLaunch.

Obsługiwany profil to `Omsi23004_692EBFBF`; nieznany plik OMSI jest odrzucany
przed uruchomieniem.

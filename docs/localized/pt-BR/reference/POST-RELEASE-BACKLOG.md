# Backlog pós-lançamento

Situação: NORMATIVA

A primeira versão atual não deve expor mutação insegura de ponteiro/lista genérico.
O trabalho a seguir é intencionalmente pós-lançamento, a menos que um perfil exato vinculado
a operação semântica fecha antes do portão de liberação:

- Indução segura de tempo de execução e validação de ciclos de perda/redefinição de dispositivo D3D9 e um
  solicitar redefinição de corrida. Status do dispositivo e criação/atualização/consulta/liberação de textura
  já foram comprovados em tempo de execução com alças opacas do OmsiLaunch.
- Religação de veículo cruzado/espacial/ODE. As transformações locais não são corretas
  teletransporte ou uma primitiva de replicação de autoridade.
- Controle de fantoches de veículos autorizados de alta frequência.
- Gravações genéricas de ponteiro/lista e APIs ODE de baixo nível.
- Modo de compatibilidade OmsiHook RPC.
- Portas NT6 e XP legadas, após `legacy-port-base` ser congelado.

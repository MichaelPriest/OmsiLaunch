# Documentação do OmsiLaunch

Esta é a documentação canônica em inglês do OmsiLaunch `0.1.0-beta1`.
OmsiLaunch fornece inicialização programável, gerenciamento de sessão e tempo de execução
controle para a compilação exata do OMSI 2 documentada na referência de compatibilidade.

Comece com [instalação](getting-started/installation.md) e
[sua primeira sessão](getting-started/installation.md). O
[referência de controle local](getting-started/installation.md) documenta a CLI e o local
superfície de controle de tempo de execução. Consulte [limitações conhecidas](getting-started/installation.md)
antes de confiar em capacidades experimentais.

Cópias localizadas estão disponíveis em `docs/localized/`. Inglês é normativo
quando a redação técnica for diferente.

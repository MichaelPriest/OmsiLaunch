# OmsiLaunch 0.1.0-beta1

**Tag vorbereitet:** `v0.1.0-beta1`  
**Titel der Veröffentlichung:** „OmsiLaunch 0.1.0-beta1“.  
**Vorabveröffentlichung:** ja

## Highlights

- Programmierbare „LaunchSpec“, „PlanSession“, Sitzungslebenszyklus und Referenz
  CLI sind für das unterstützte OMSI-Build-Profil verfügbar.
- Permanente Produkt-Plugin-Dateien werden unter „plugins\OmsiLaunch.*“ installiert.
- Temporäre Konfigurations- und verwaltete Splash-Änderungen werden protokolliert und wiederhergestellt
  Byte für Byte.
- Von PTB, ENG, DEU und FRA verwaltete Splash-Assets sind enthalten.
- Das Release-Paket enthält ein tragbares Grundorf-Sitzungsbeispiel und eine kleine
  Offline-Benutzerhandbuch.

## Kompatibilität

Diese Beta unterstützt nur „Omsi23004_692EBFBF“. Unbekanntes oder nicht profiliertes OMSI
Ausführbare Dateien werden abgelehnt. Konsultieren Sie den Funktionskatalog und bekannte Einschränkungen
vorher abhängig von experimentellen Laufzeitsteuerungen.

# OmsiLaunch-Dokumentation

Dies ist die kanonische englische Dokumentation für OmsiLaunch „0.1.0-beta1“.
OmsiLaunch bietet programmierbaren Start, Sitzungsverwaltung und Laufzeit
Steuerung für den genauen OMSI 2-Build, der in der Kompatibilitätsreferenz dokumentiert ist.

Beginnen Sie mit [Installation](getting-started/installation.md) und
[Ihre erste Sitzung](getting-started/installation.md). Die
[local control reference](getting-started/installation.md) dokumentiert die CLI und die lokale
Laufzeit-Kontrolloberfläche. Siehe [bekannte Einschränkungen](getting-started/installation.md)
bevor man sich auf experimentelle Möglichkeiten verlässt.

Lokalisierte Kopien sind unter „docs/localized/“ verfügbar. Englisch ist normativ
wenn der technische Wortlaut unterschiedlich ist.

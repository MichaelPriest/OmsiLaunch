# OmsiLaunch 0.1.0-beta1

**Tag prepared:** `v0.1.0-beta1`  
**Release title:** `OmsiLaunch 0.1.0-beta1`  
**Pre-release:** yes

## Highlights

- Programmable `LaunchSpec`, `PlanSession`, session lifecycle, and reference
  CLI are available for the supported OMSI build profile.
- Permanent product plugin files are installed under `plugins\OmsiLaunch.*`.
- Temporary configuration and managed splash changes are journaled and restored
  byte-for-byte.
- PTB, ENG, DEU, and FRA managed splash assets are included.
- The Release package includes a portable Grundorf session example and a small
  offline user guide.

## Compatibility

This beta supports `Omsi23004_692EBFBF` only. Unknown or unprofiled OMSI
executables are rejected. Consult the capability catalog and known limitations
before depending on experimental runtime controls.

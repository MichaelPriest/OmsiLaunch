# OmsiLaunch Documentation

This is the canonical English documentation for OmsiLaunch `0.1.0-beta1`.
OmsiLaunch provides programmable launch, session management, and runtime
control for the exact OMSI 2 build documented in the compatibility reference.

Start with [installation](getting-started/installation.md) and
[your first session](getting-started/first-session.md). Standalone or manually
installed OMSI copies can be selected explicitly with `/exe:<path-to-Omsi.exe>`
when the executable matches a supported exact-build profile. The
[local control reference](api/local-control.md) documents the CLI and local
runtime-control surface. See [known limitations](reference/known-limitations.md)
before relying on experimental capabilities.

Localized copies are available under `docs/localized/`. English is normative
when technical wording differs.
